## 🚀 运行测试

```bash
# 安装依赖
composer install

# 运行所有测试
./vendor/bin/phpunit

# 运行特定测试
./vendor/bin/phpunit tests/SecurityTest.php

# 生成覆盖率报告
./vendor/bin/phpunit --coverage-html coverage

# 运行安全测试
./vendor/bin/phpunit tests/SecurityTest.php
```

## 📝 测试最佳实践

1. **每个测试独立** - 不依赖其他测试的状态
2. **使用有意义的断言** - 清晰的错误信息
3. **覆盖边界情况** - 空值、最大值、最小值
4. **测试错误处理** - 异常和错误响应
5. **保持测试简洁** - 一个测试一个断言
